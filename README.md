# 社会科学量化方法自学图谱

从研究问题开始，逐步读懂方法、解释结果、完成一篇量化论文。面向初学者，以中文讲解为主，保留规范英文术语；操作示例以 R 为主，兼顾其他软件。

**当前版本：v1.0 · Windows 10/11 x64 · 私有试发布**

[下载安装包](https://github.com/RaytonXia/social-science-methods-atlas/releases/tag/v1.0) · [使用说明](使用说明.txt) · [添加新方法](app/contribute/README.md) · [构建说明](docs/BUILD.md)

## 下载与安装

进入上面的 Release 页面，在 **Assets** 中选择：

| 文件 | 适合谁 | 怎样打开 |
| --- | --- | --- |
| `MethodAtlas_v1.0_Setup.exe` | 希望从开始菜单启动，推荐 | 下载后运行，按中文向导安装 |
| `MethodAtlas_v1.0.zip` | 希望免安装使用 | 完整解压，进入“社会科学量化方法自学图谱_v1.0”文件夹运行同名 EXE |
| `SHA256_v1.0.txt` | 希望核对下载文件 | 用 SHA256 校验文件完整性 |

Release 页面自动提供的 **Source code** 是维护源码，不是可直接运行的安装包。本仓库目前为私有，下载需要获准访问的 GitHub 账号。

GitHub 下载附件使用英文文件名，并显示中文标签；应用名称、安装界面和 ZIP 内文件夹保留中文名称。

程序依赖 .NET Framework 4.6.2 或更高版本，以及 Microsoft Edge WebView2 Runtime。已有 WebView2 的电脑可以离线安装；缺少时，安装向导会提示使用微软组件安装程序联网补齐。安装包目前未做代码签名。

## 可以学什么

- **176 个方法与基础条目**：按用途、原理、准备条件、结果解读、实际步骤、结论局限展开六个关键问题。
- **从零开始的 12 课**：从研究问题、文献和测量，走到 R 分析、诊断与论文写作。
- **发展脉络与分类树**：按年份回顾 1662—2026 年的 89 个事件，通过研究问题和相关方法继续阅读。
- **73 份离线读物**：完整发行包包含原文阅读、目录、全屏、翻页、阅读位置记忆和英文单词查译。选段翻译与外部课程、视频需要联网。
- **学习记录**：收藏、笔记、学习状态、复习安排、课程草稿，以及导出和导入备份。
- **可选 AI 助手**：读者自行开启并配置 DeepSeek、OpenAI、Claude 或 Gemini API。未配置时不影响核心学习功能。

## 学习记录和 API

Windows 学习记录位于当前用户的 `%LOCALAPPDATA%/MethodAtlas/WebView`。更新应用和卸载程序保留此目录；换设备前，请在“我的学习”导出备份。

AI 助手默认关闭。密钥只保留在当前会话内存中，发行包不含共享密钥。只有发送问题或读取模型列表才请求服务商；附带当前方法说明需要读者主动勾选。选段翻译按界面提示发送所选文字。具体说明见[使用说明](使用说明.txt)。

## 维护方法内容

应用中打开“方法词典 → 添加方法”，或读取 [维护规范](app/contribute/README.md) 和 [AI 维护约定](app/contribute/AGENTS.md)。先生成模板、校验和预览，再入库。校验全部条目：

```sh
python app/contribute/method_tool.py check-app
```

网页和教学数据位于 `app/`。完整 PDF 通过 Release 分发，不重复提交到 Git；恢复读物和构建 Windows 程序见[构建说明](docs/BUILD.md)。仓库包含启动器与 AI 连接组件源码，但既有 `Atlas.Shell.dll` 仅提供编译产物，不宣称已包含完整原生外壳源工程。本次不发布未同步更新的 Android APK。
