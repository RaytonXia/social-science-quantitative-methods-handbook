社会科学量化方法学自学图谱

打开软件
免安装版：完整解压“社会科学量化方法自学图谱_v1.0.zip”，进入同名文件夹，双击“社会科学量化方法自学图谱_v1.0.exe”。
安装版：运行“社会科学量化方法自学图谱_v1.0_Setup.exe”，按中文向导完成安装，再从开始菜单打开。默认只安装到当前用户的 LocalAppData/Programs/MethodAtlas，无需管理员权限。
已有 WebView2 Runtime 的电脑可以离线安装；缺少该组件时，安装向导会提示使用微软安装程序联网补齐。免安装版也可在 runtime 文件夹手动运行微软组件安装程序。
卸载入口在 Windows“已安装的应用”和开始菜单中。卸载只移除随包安装的文件，保留 MethodAtlas/WebView 中的学习记录；用户自行放进程序目录的其他文件也会保留。
请保留 app 文件夹、DLL 和配置文件，不能只复制 EXE。
运行环境：Windows 10/11 x64；.NET Framework 4.6.2 或更高；Microsoft Edge WebView2 Runtime。
WebView2 官方入口：https://developer.microsoft.com/en-us/microsoft-edge/webview2/
若软件已经打开，请先关闭再重新打开，以读取完整的应用内容。

从哪里开始
第一次学习：学习首页 → 从零开始。12 课依次引导研究问题、文献、测量、设计、样本计划、R 分析、诊断与论文写作。
方法词典可按中文、英文、缩写、方法族、难度和软件查找。
遇到不熟悉的统计词，打开方法页的“先弄懂这几个词”或顶部“中英术语”。30 个基础词条提供解释、数值例子和常见误解。
每个方法直接展开六个问题：用途、原理与例子、准备条件、关键结果、实际步骤、结论与局限。
结果表按阅读顺序说明每个指标的含义、具体数值和判断时要注意的地方。表中的示例数字不冒充实际研究结果。
数学基础从具体数字讲起；RSA 可检索“RSA”“响应面”或“a1”，并对照两条带数值的截面图理解 a1–a4。
发展脉络按年份回顾 1662—2026 年的 89 个事件，可按年代、研究主题或关键词查找。展开事件可查看它改变了什么、解释边界、相关方法及原始文献。方法分类树提供另一种查找入口。标签用于选择学习入口，不是方法优劣排名。

AI 助手
点击顶端“AI 助手”，或阅读器中的“AI 问答”。助手默认关闭；手动开启后，选择 DeepSeek、OpenAI、Claude 或 Gemini，填入自己的 API Key 和模型 ID，再发送问题。也可点击“读取模型列表”获取账号可见的模型；列表中的模型不一定都支持文字问答，请按服务商说明选择。
打开面板和开启开关不会自动调用 API。只有发送问题或读取模型列表才连接所选服务商，实际使用可能产生服务商费用。联网条件、账号权限、模型权限和额度会影响可用性。
密钥与对话仅保留在本次运行的内存中。收起面板可以继续本次问答；关闭助手开关或退出软件会清除密钥与对话。只记住服务商和模型 ID，学习记录备份不包含密钥。
助手不会自动发送学习笔记、阅读历史或导入的文件。在方法页可以勾选“附上当前方法的教学说明”，先查看摘录，再决定是否随问题发送。问答用于帮助理解，涉及统计结论和引用时仍应核对原始文献。

原文与课程
正文和 73 份完整 PDF 可离线使用，包含教材、论文和官方参考手册；外部课程、视频与期刊入口需要联网。
RSA 官方手册可从方法页的“配套原文与课程”直接打开，也可在本地书架搜索。
阅读器提供原始版式、排版阅读、全屏、目录、页码跳转、左右区域点击翻页、渐变动画与阅读位置记忆。
英文单词可离线查译；选段翻译需要联网，按界面提示发送选中的文字。扫描图片和复杂公式的文字提取可能受限，请对照原件。
文献下载清单包含 966 条来源记录，与应用内目录一致。可按文件状态筛选，记录已取得的原件；73 份内置 PDF 无需重复下载。
来源可达情况有检查日期，登录、订阅、地区及网络变化可能影响外部访问。

练习与代码
应用不直接执行 R。数学基础提供小型 R 示例；RSA 代码先生成模拟数据，再拟合和读取曲面参数。
其他代码中出现 dat、x、y 等名称时，需要先按说明整理数据并替换变量名。代码的演示数据不一定对应正文的教学数值。
“入门论文练习”提供基于 R 自带 swiss 历史地区数据的练习；地区关联不能直接解释成个人因果效应。

学习记录
收藏、学习状态、分步勾选、笔记、复习安排及课程草稿保存在当前设备。
Windows 数据位置：当前用户 LocalAppData/MethodAtlas/WebView。
请在“我的学习”导出 JSON 备份；迁移或清理设备前保留备份和自行导入的 PDF 原件。
应用内容文件与学习记录分开存放；不要删除上述用户数据目录。
