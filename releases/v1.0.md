# 社会科学量化方法自学图谱 v1.0

面向社会科学量化研究初学者的 Windows 学习应用。当前为私有试发布，只有获准访问仓库的账号能够下载。

## 下载安装

- 推荐下载 `MethodAtlas_v1.0_Setup.exe`，按中文向导安装。
- 免安装使用请选择 `MethodAtlas_v1.0.zip`，完整解压后进入“社会科学量化方法自学图谱_v1.0”文件夹，运行其中的同名 EXE。
- `SHA256_v1.0.txt` 用于核对文件完整性。GitHub 自动提供的 Source code 不是安装包。

附件保留中文显示标签；为避免 GitHub 自动删除中文下载文件名，实际下载名使用 MethodAtlas。应用、安装界面和 ZIP 内文件夹仍使用中文名称。

## 本版内容

176 个方法与基础条目、12 课入门引导、89 个历史事件、73 份离线原文，以及方法分类树、阅读器、学习记录和可选 AI 助手。方法维护入口位于“方法词典 → 添加方法”。

已修复启动时提示“软件组件未能启动”的初始化顺序问题。免安装版与安装后的实际 Windows 启动验证均通过；安装、快捷方式、卸载保留资料与发行包完整性检查通过。

## 使用条件与说明

Windows 10/11 x64，.NET Framework 4.6.2 或更高，Microsoft Edge WebView2 Runtime。缺少 WebView2 时安装向导会提示联网补齐。安装包目前未做代码签名。AI 问答、选段翻译和外部资料需要联网；API 由读者自行配置。本次未同步发布 Android APK。

原学习记录仍位于 `%LOCALAPPDATA%/MethodAtlas/WebView`。更新和卸载保留该目录，换设备前请导出学习备份。

部分第三方资料的再分发许可尚待逐项复核，所以本仓库及此 Release 保持私有；转为公开前查看 `docs/THIRD_PARTY.md`。
