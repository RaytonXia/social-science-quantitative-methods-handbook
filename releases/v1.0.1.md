# 社会科学量化方法自学手册 v1.0.1

**一本面向初学者的互动教科书。** 从作者的社会心理学量化研究自学出发，帮助读者探索方法、看懂结果、跟着练习和阅读原文。

本版提供 176 个方法与基础条目、12 课学习引导、89 个历史事件、方法分类树、学习记录和可选 AI 助手。Windows 10/11 x64；R 示例在自己的 R 环境运行。

- 内置 63 份许可可核查的完整原文；另 10 份保留官方获取入口。28 份 R 包手册附对应版本源码及声明。
- 原文书架可筛选“已内置 / 官方获取”；旧阅读链接会显示获取说明，避免尝试打开未随包提供的文件。
- 应用、安装包与项目说明统一为“社会科学量化方法自学手册”；学习记录位置保持不变。
- 新增项目介绍与建议入口，欢迎老师和同学反馈内容、教学和使用问题。

下载安装包 `QuantMethodsHandbook_v1.0.1_Setup.exe`，或完整解压 `QuantMethodsHandbook_v1.0.1.zip`。核对文件可使用 `SHA256_v1.0.1.txt`。Source code 不是安装包。

项目自有代码及原创教学内容未经作者事先书面许可不得用于商业目的；第三方资料保持各自许可。详细依据见 [第三方说明](https://github.com/RaytonXia/social-science-quantitative-methods-handbook/blob/main/docs/THIRD_PARTY.md)。

欢迎[提出建议或报告问题](https://github.com/RaytonXia/social-science-quantitative-methods-handbook/issues/new/choose)。本次提供 Windows 版，Android APK 尚未同步本版。安装包尚未代码签名。
