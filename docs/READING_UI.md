# 阅读与学习记录

顶栏的“返回”和前进按钮沿本次阅读路径移动。返回时恢复阅读位置、展开的讲解、教学练习中的数字，以及方法词典的筛选条件。从方法页打开内置原文后，也可以用阅读器左上角的“返回”回到刚才的方法。阅读路径只保留在本次运行中。

方法页的四个检查卡片用于记录已经做过的练习。勾选后会立即更新计数，记录仍使用原来的存储位置和方法编号。复习按钮可安排明天或一周后的复习；这些记录不代表已经完全掌握该方法。

每一页右下角都有 AI 助手入口。打开后的面板不锁住正文，读者可以继续查方法、看资料。点击面板右上角的叉号或按 Esc 收起，配置、对话和未发送的问题在本次运行中保留；点击“关闭并清空”才会清除密钥和本次问答。退出软件后密钥与对话不保留，笔记和学习记录继续保存在本机。

切换方法时，面板会更新“正在阅读”的标题。教学摘录仍须由读者勾选后随问题发送；切换页面、展开或收起面板不会自动发起模型请求。
