# 社会科学量化方法自学手册 v1.1.1

一本帮助初学者查方法、看懂统计输出、读原文和练习写量化论文的互动教科书。中文讲解配英文术语，代码示例以 R 为主。

本版汇总自上一个公开版 v1.0.2 以来的教学与软件更新。

## 更新了什么

- **把方法和指标讲得更清楚。** 176 个方法与基础条目配有逐步例子、717 项指标与诊断说明、176 道独立自测题。先解释一个数表示什么，再说明正负、大小、单位、区间及不能据此推出的结论。
- **增加能改数字的教学练习。** 求和、均值标准误、优势比（OR）和响应面分析（RSA）支持直接改变数字并观察图形与结果。教学设定与真实研究输出明确区分。
- **跳转后能回到刚才读的地方。** 顶栏支持返回与前进；返回时保留原方法的阅读位置、展开内容、练习数字和词典筛选条件。从方法页进入原文后，也能直接返回。
- **整理学习记录的排版。** 四张检查卡片统一对齐、字号和间距，勾选后立即更新计数；复习安排与学习记录继续保存在原位置。
- **AI 助手可以边读边问。** 各页面右下角保留入口，面板展开后可继续操作正文。收起保留本次配置、对话和草稿；点击“关闭并清空”或退出软件才清除密钥与问答。
- **修复安装目录检查。** 已存在的空文件夹可以正常安装；识别旧版目录，误选其他非空目录时会给出明确提示。
- **完善维护入口。** 新方法模板支持逐步讲解、指标卡和图示；同时修正源码文本格式转换后可能出现的资源校验误报。

原有 12 课入门引导、89 个方法史事件、63 份离线读物和方法维护入口继续保留。修正了部分文献年份与 DOI 的对应信息。

## 下载与升级

- 安装版：下载 `QuantMethodsHandbook_v1.1.1_Setup.exe`，关闭正在运行的旧版后安装。
- 免安装版：下载 `QuantMethodsHandbook_v1.1.1.zip`，完整解压，打开 `社会科学量化方法自学手册_v1.1.1.exe`；保留同目录的 app、DLL 和配置文件。
- `SHA256_v1.1.1.txt` 用于核对下载完整性，`UPDATE_NOTES_v1.1.1.md` 是本说明的可下载版本。

支持 Windows 10/11 x64，需要 .NET Framework 4.6.2 或更高版本及 Microsoft Edge WebView2 Runtime。已有 WebView2 时可离线安装，缺少时向导会提示联网补齐。安装包目前没有代码签名。本次发布 Windows 版。

升级与卸载保留独立的 MethodAtlas 学习记录目录。迁移设备前，仍建议从“我的学习”导出备份，并单独保存自己导入的 PDF。
