# 方法词典维护入口

修改前先读本目录 README.md，再用 method_tool.py 的 catalog 和 template 命令获取当前编号、分类与模板。不要沿用旧版本数据。

- 只增加用户指定的方法。已有方法的编号永久保留，学习记录依赖编号；不要重排、复用或整体替换词典。
- 六个关键问题必须逐一回答。以初学者能跟着操作、读懂输出为标准；指标表必须说明方向、大小、单位、不确定性及不能推出的结论。细则见 README.md。
- 使用规范中文名称，同时给专业英文名称与检索别名。不要把生硬直译当成已有通行译名。
- 只引用已实际查阅的真实来源；记录支持的具体章节、表、公式或页面。链接响应成功不能代替核对题名、作者、年份与内容。搜索结果摘要不能作为完整阅读证据。
- 数字例子与代码必须核算；模拟数据明确标作教学示例。没有实际运行的代码如实说明。校验器不执行代码、不联网，也不判断学术结论是否正确。
- 中文／英文 × 文字／视频分别寻找；找不到合适资源就写明缺口，不编造、不把泛用课程冒充该方法专门教程。R 优先，其他软件按适用性补充。
- 用本地 JSON 草稿、check、preview、add 完成新增。预览通过后才执行 add；add 只增加新编号，不支持覆盖旧方法。
- 新增后运行 check-app，并在真实浏览器核对搜索、标签、六个问题、指标表、学习步骤、关联方法、图谱和资源链接。手机与桌面布局均需检查。
- 不改 Logo、整体版式、旧方法正文、学习记录存储键或读者数据。维护草稿、备份、测试样本不属于读者教学内容。
- 新文献下载进入发行包之前，确认允许再分发；可公开阅读不等于可随软件公开发布。不得提交学习记录、私人 PDF、缓存、签名密钥和凭据。
- 用户目前只安排本地维护入口；GitHub 发布需要后续明确指令，不自动上传、建仓库或创建公开链接。
